Fixes for placing and linking locations on the map.

## Added

- Drag a location to move it in Creation. Its links update.
- One legend for Creation and Map View.

## Changed

- Technology, marker and link colours are the same in both map views.

## Fixed

- Locations and links created at the same moment no longer share an id.
- Link mode picks the nearest model location, so clicking an OpenStreetMap substation or plant creates the link.

## Downloads

- Windows: `TEMPO.Setup.4.1.1.exe`
- Linux: `TEMPO-4.1.1.AppImage`, `tempo_4.1.1_amd64.deb`
