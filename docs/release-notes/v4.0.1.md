Updates from inside the app, model checks before you run, and interface polish.

## Added

- In-app updates. TEMPO checks GitHub releases at startup and every 6 hours, checks the download and installs it.
- Model readiness checks in the Save dialog and the Run view, with links to fix each problem.
- Multi-carrier conversion technologies on all five engines.
- Italian, UK and Cambridge templates download on demand.
- Custom title bar with app menus, and guided tours.
- Grey map style.

## Changed

- Templates are no longer bundled, so the installers are smaller.
- Resource scaling and demand handling match across the engines.
- Redesigned dashboard overview, result charts, solver log viewer, notifications and dropdowns.
- Switch models from the sidebar.

## Fixed

- Guided tour restarts every time.
- Title bar shows the right title.
