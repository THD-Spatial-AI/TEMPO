Engine installs no longer fail on machines whose default Python is too new.

## Fixed

- Calliope 0.7, PyPSA, OSeMOSYS and AdOpT-NET0 failed to install with "Microsoft Visual C++ 14.0 or greater is required" or "Could not find vswhere.exe" when the system Python was 3.14 or newer, or 32-bit. TEMPO now uses only a 64-bit Python 3.10 to 3.13, and on Windows downloads Python 3.12 when none fits.
- If an engine venv was built with another Python, reinstall the engine from Settings.

## Downloads

- Windows: `TEMPO.Setup.4.2.1.exe`
- Linux: `TEMPO-4.2.1.AppImage`, `tempo_4.2.1_amd64.deb`
