# TEMPO 4.2.2

A coarser time resolution (e.g. 3-hourly) now runs on Calliope 0.6.8, Calliope 0.7 and PyPSA, and Calliope 0.7 applies the reserve margin.

## Fixed

- A `model.time` resample override (e.g. `res_3H`) or `modelConfig.timeResolution` now resamples on Calliope 0.6.8, Calliope 0.7 and PyPSA. Before, Calliope 0.7 solved hourly and PyPSA skipped the override.
- Calliope 0.7 applies the reserve margin (`run.reserve_margin`, or `model.reserve_margin` in an override), as Calliope 0.6.8 does.
