# TEMPO 4.2.3

Calliope 0.7 runs models whose overrides mix tech switches with a time resolution, and PyPSA installs a dependency stack that gives the right objective.

## Fixed

- Calliope 0.7 failed with "definition.model Extra inputs are not permitted" when an override only switched techs off (`exists: false`) next to `res_3H` or the "3-Hour Resolution" template. Those overrides are now translated.
- PyPSA gave a wrong objective with pandas 3.1. The install pins pypsa 0.35.2, pandas 2.3.1, xarray 2025.6.1 and linopy 0.5.5, and an existing PyPSA environment is corrected when the service starts.
