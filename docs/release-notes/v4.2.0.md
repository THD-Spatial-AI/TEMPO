Problems in a model now point to the thing to fix, and the SPORES figures of Lombardi et al. (2020) work for any run.

## Added

- Model check with critical, error and warning levels. Only critical problems block a run, and every item has a Fix link.
- Edit a model's own scenarios and overrides in Scenario Studio, with a guided builder.
- One saved time window per model.
- Electricity demand card on locations.
- SPORES Figures 1 to 6 and Tables 1, S1 and 2, with PNG, SVG and CSV export.
- Import result, to load a result contract as a run.

## Changed

- The SPORES tab shows the paper figures first.
- Demand and catalog technologies follow the model unit.

## Fixed

- Calliope 0.6.8 scenario and override runs solved the baseline. Run old scenario results again.
- Two parallel solves in one Calliope service could deadlock.
- Scenario Studio dropped results and ran the full year.
